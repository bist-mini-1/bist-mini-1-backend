## 💻 빠른 시작 (Quick Start)

가장 빠르게 프로젝트를 실행하는 방법입니다.

1.  **환경 설정**: [ENVIRONMENT.md](./docs/ENVIRONMENT.md)를 참고하여 `.env` 파일을 생성합니다.
2.  **의존성 설치 및 빌드**:
    ```bash
    .\gradlew clean build
    ```
3.  **실행**:
    ```bash
    .\gradlew bootRun
    ```
