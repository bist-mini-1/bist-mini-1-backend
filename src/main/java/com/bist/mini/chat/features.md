# 채팅 시스템 기능 명세 (Feature Specification)

## 15. 채팅 (Chatting)

### 15.1 채팅방 관리
- **17.1.1 1:1 채팅방 생성**: 특정 사용자와의 채팅방 개설 기능
- **17.1.2 채팅방 목록 조회**: 사용자가 현재 참여 중인 채팅방 목록 조회

### 15.2 메시지 전송
- **17.2.1 텍스트 메시지**: 실시간 텍스트 메시지 송수신
- **17.2.2 이미지/파일 전송**: 채팅 중 이미지 및 각종 파일 공유 기능

### 15.3 채팅 내역 관리
- **17.3.1 대화 내역 로드**: 이전 채팅 메시지 페이징(Scroll-based) 조회

### 15.4 알림 (Notification)
- **17.4.1 새 메시지 알림**: 채팅방 외부에 있을 때도 실시간 메시지 수신 알림 제공
