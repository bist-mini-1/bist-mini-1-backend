# 채팅 시스템 스키마 (Oracle)

## 1. 채팅방 (chat_rooms)
채팅방 마스터 정보 테이블

```sql
CREATE TABLE chat_rooms (
    room_id         NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    room_name       VARCHAR2(100),
    room_type       VARCHAR2(20) DEFAULT 'PERSONAL' NOT NULL,
    created_at      DATE DEFAULT SYSDATE NOT NULL,

    CONSTRAINT ck_chat_room_type CHECK (room_type IN ('PERSONAL', 'GROUP'))
);

COMMENT ON COLUMN chat_rooms.room_type IS '채팅방 타입 (PERSONAL: 1:1, GROUP: 그룹)';
```

## 2. 채팅방 멤버 (chat_room_members)
채팅방별 참여자 정보 및 읽음 상태 관리

```sql
CREATE TABLE chat_room_members (
    room_member_id  NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    room_id         NUMBER NOT NULL,
    member_id       NUMBER NOT NULL,
    joined_at       DATE DEFAULT SYSDATE NOT NULL,
    last_read_at    DATE,

    CONSTRAINT fk_chat_member_room FOREIGN KEY (room_id) REFERENCES chat_rooms(room_id),
    CONSTRAINT fk_chat_member_member FOREIGN KEY (member_id) REFERENCES members(member_id),
    CONSTRAINT uk_chat_room_member UNIQUE (room_id, member_id)
);

COMMENT ON COLUMN chat_room_members.last_read_at IS '마지막으로 메시지를 읽은 시간';
```

## 3. 채팅 메시지 (chat_messages)
채팅 메시지 내역

```sql
CREATE TABLE chat_messages (
    message_id      NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    room_id         NUMBER NOT NULL,
    sender_id       NUMBER NOT NULL,
    message_type    VARCHAR2(20) DEFAULT 'TEXT' NOT NULL,
    content         CLOB NOT NULL,
    created_at      DATE DEFAULT SYSDATE NOT NULL,

    CONSTRAINT fk_chat_msg_room FOREIGN KEY (room_id) REFERENCES chat_rooms(room_id),
    CONSTRAINT fk_chat_msg_sender FOREIGN KEY (sender_id) REFERENCES members(member_id),
    CONSTRAINT ck_chat_msg_type CHECK (message_type IN ('TEXT', 'IMAGE', 'FILE'))
);

COMMENT ON COLUMN chat_messages.message_type IS '메시지 타입 (TEXT, IMAGE, FILE)';
```
