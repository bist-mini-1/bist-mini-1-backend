# 회원 테이블 스키마 (Member Schema)

```sql
CREATE TABLE members (
    member_id       NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    login_id        VARCHAR2(50) NOT NULL,
    password        VARCHAR2(255) NOT NULL,
    email           VARCHAR2(100) NOT NULL,
    nickname        VARCHAR2(50) NOT NULL,
    bio             VARCHAR2(1000),
    profile_image   VARCHAR2(500),
    status          VARCHAR2(20) DEFAULT 'ACTIVE' NOT NULL,
    created_at      DATE DEFAULT SYSDATE NOT NULL,
    updated_at      DATE,
    deleted_at      DATE,

    CONSTRAINT uk_members_login_id UNIQUE (login_id),
    CONSTRAINT uk_members_email UNIQUE (email),
    CONSTRAINT uk_members_nickname UNIQUE (nickname),
    CONSTRAINT ck_members_status CHECK (status IN ('ACTIVE', 'DELETED'))
);
```

- `bio`: 자기소개
- `status`: 회원 상태 (ACTIVE, DELETED)
